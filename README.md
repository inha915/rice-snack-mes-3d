# Rice Snack Factory · 3D MES

베트남 쌀과자 공장의 공정을 3D로 보여주는 디지털 트윈 + MES 대시보드 프론트엔드입니다. React + Vite + Three.js.

## 실행
```powershell
npm install
npm run dev      # http://127.0.0.1:5173
npm test         # 공정 구조 · 생산 계산 · 실시간 카운터 테스트
npm run build    # dist/ 생성
```

## 공정 구조 (`src/process.js`)
- **베이스 라인 1개 · 10공정:** 원료 투입·세미 → 침지(10조, 공용 컨베이어 합류) → 증숙·혼련(탈수 없음) → 압출·냉각 → 압연·원형 타발 → 1차 건조 → 반제품 검사·적재 → 2차 건조(수분 ≤10%) → 예열·유탕 → 분말 조미·냉각
- **국가별 소포장 라인 A/B/C:** 개별 소포장, 실링 온도 수집 (`PACK_LINES`에서 라인 수·국가명 변경)
- **최종 포장 라인 1개 (별도 방):** 묶음 외포장부터 A/B/C 합류 → 중량선별·금속검출 → 제함·박스 → 6축 협동로봇 팔레타이징

3D와 공정 도면은 모두 `plantLayout()` 하나를 기준으로 그립니다.

## 화면
- **3D 공장:** 설비별 모델, 제품 흐름 애니메이션, 설비 위 데이터 창(온도·투입량·생산량·봉지·묶음·박스·NG), 실시간 집계 창, 패널 열기/닫기
- **공정 도면:** 공정 흐름도, 평면 배치도, 포장 공정 상세, 수정 내역
- **설비 온도 / 원료·생산량 / 생산 이력:** 온도 추이, 배치 계산, CSV 내보내기

## 데이터
- 모든 수치는 데모 시뮬레이션입니다 (`src/live.js`, `src/data.js`). 포장 단위, 실링 온도 기준, 투입 속도 등은 가정값입니다.
- PLC는 브라우저에 직접 연결하지 않습니다. 서버 측 게이트웨이(OPC UA/Modbus 등)에서 WebSocket/REST로 받아 `applyTelemetry()`로 반영하는 구조를 전제로 합니다.
- 배치 기록과 패널 설정은 브라우저 localStorage에만 저장됩니다.

## 참고
- 설비 형상은 개략 모델이며 실측 CAD가 아닙니다.
- 현장 참고 사진(`public/references/`)과 내부 메모(`docs/`)는 저장소에 포함하지 않습니다. 로컬에 사진이 있으면 공정 상세 카드에 표시되고, 없으면 숨겨집니다.
